# xCloud Enhancer 1.0 (Android / Android TV)

## Gerar o APK
**A) GitHub Actions (sem instalar nada):** envie esta pasta para um repositório, aba Actions → "Build APK" → Run workflow → baixe o artefato `xcloud-enhancer-apk`.
**B) Android Studio:** abra a pasta → Build → Build APK(s).

## Instalar
- Celular: abra o .apk e permita fontes desconhecidas.
- Android TV: copie o .apk (pendrive/Send Files to TV) e abra com um gerenciador de arquivos.

## Primeiros passos
1. Faça login normalmente.
2. Painel: ⚙ (fora do jogo), Hub do Xbox (durante o jogo) ou View + Menu (segure 1 s).
3. Leia `docs/EXPLICACAO-TECNICA.md`.

O script `app/src/main/assets/xcloud-enhancer.user.js` também funciona em Tampermonkey/Violentmonkey.
