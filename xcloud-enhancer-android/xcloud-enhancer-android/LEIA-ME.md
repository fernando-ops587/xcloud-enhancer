# xCloud Enhancer (Android / Android TV)

## Opção A: Android Studio
1. Abra esta pasta no Android Studio e aguarde o sync.
2. Build > Build APK(s). O APK sai em app/build/outputs/apk/debug/.

## Opção B: sem instalar nada (GitHub Actions)
1. Crie um repositório no GitHub e envie o conteúdo desta pasta.
2. Aba Actions > "Build APK" > Run workflow.
3. Quando terminar, baixe o artefato "xcloud-enhancer-apk" (zip com o .apk).

## Instalar
- Celular: abra o .apk e permita "instalar de fontes desconhecidas".
- Android TV: copie o .apk por pendrive ou use o app "Send Files to TV"; abra com um gerenciador de arquivos.
